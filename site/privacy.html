Privacy notice

AI Shiksha does not require a learner account and does not include analytics, advertising, or cloud AI requests in this demo.

Lesson progress, assessment scores, project journals, and ML Studio projects are stored locally in the current browser or application storage. Clearing browser/application data removes those locally stored records unless the learner exported a backup first.

Images selected for ML Studio are reduced to small thumbnails and numeric visual features on the device. The demo does not upload those images to this GitHub repository or another service.

The Android APK is a debug-signed hackathon build. It should be replaced by a signed production build before general distribution.
